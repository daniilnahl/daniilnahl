### Projects

[AQMod — Air Quality Module](https://github.com/daniilnahl/AQMod) -> ESP32-S3-based air quality monitor integrating BMP280, MQ-9, and SEN54 sensors to track particulate matter, VOCs, methane, temperature, and pressure. Progressed from a working prototype through FreeRTOS integration, BLE connectivity, and on-device TinyML classification for real-time inference. Tech: ESP32-S3, FreeRTOS, Edge Impulse (TinyML), I2C/analog sensor drivers, BLE.
